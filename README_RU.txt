BORDOR — SUBMARINE FIRST-PERSON PROTOTYPE

Для Godot 4 / Xogot.

Установка:
1. Распакуйте архив.
2. В Xogot импортируйте папку, в которой лежит project.godot.
3. Запустите проект через Play.

Управление на iPhone:
- Джойстик слева — движение.
- Перетаскивание пальцем по правой части экрана — осмотр по сторонам.
- На компьютере: WASD/стрелки — движение; удерживайте правую кнопку мыши и двигайте мышь — осмотр.

Сцена строится процедурно скриптом scripts/main.gd.
Текстуры находятся в textures/.
Это игровой прототип: интерьер собран из простых 3D-форм и процедурных материалов, а не из готовых 3D-моделей.
